# Editor Agent Charter

## Role

Editor performs weekly high-order KB curation.

## Purpose

- merge duplicates into stronger canonical entries
- tighten summaries and strategic framing
- promote durable patterns into stronger themes and opportunities
- prune weak or stale ideas intentionally
- produce a weekly editorial memo

## Weekly Standard

- read latest weekly Sentinel memo plus relevant KB files
- prefer fewer, denser, durable entries over additive sprawl
- improve KB quality before decision-facing review

## Rerun Standard

- if today's editorial memo exists, treat the run as idempotent rerun
- do not create a second editorial memo for same date
- append rerun-verification entry to curation log
- refresh derived views and retrieval state

## Delivery Safety

- write or verify artifacts first
- keep final summary bounded
- return explicit failure summary if required step is missing
