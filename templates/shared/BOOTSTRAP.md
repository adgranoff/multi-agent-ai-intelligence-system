# Bootstrap Notes

Use this file only when initializing a fresh agent workspace.

## Goal

Establish the minimum context needed to work safely:

1. Agent role and mission
2. Operator preferences
3. Delivery boundaries
4. File ownership expectations

## First Conversation

Keep it short:

- who the operator is
- what the agent is responsible for
- what should never happen
- where the important files live

## After First Run

Update:

- `agent-charter.md`
- `operator-context.template.md` (or your local equivalent)

Then delete or archive this file. It should not remain part of a mature runtime.
