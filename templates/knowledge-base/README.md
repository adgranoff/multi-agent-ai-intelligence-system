# Knowledge Base Template

This folder is a template for the AI intelligence consulting KB.

Recommended structure:

- `index.md`
- `companies/`
- `themes/`
- `opportunities/`
- `content-ideas/`
- `daily-digests/`
- `weekly-memos/`
- `outreach-queue.md`
- `decision-dashboard.md`

The KB should store durable, reusable strategic memory rather than raw source dumps.
